# Steps to think

---

## Before starting designing

1. **Clarify the goal** — Ask questions to clarify the goal, what does it mean for business?
2. **Define metrics** — What metrics are we improving specifically?
3. **Understand constraints and scope** — Do we need this real-time? How often do we need this prediction? ..

---

## Designing

### 1. Data

- Source (Database/API/logs..)
- Target variable
- Issue (Missing data/duplicates/)

### 2. Feature Engineering

- Feature importance
- Feature representation (encoding/transformation)

### 3. Model selection

- Baseline model
- Tradeoff discussion
- Training

### 4. Deployment

- Infrastructure (CI CD/scalability)
- Service

### 5. Evaluation 

- Metrics (online vs offline)
- Monitoring (dashboard tool/notebook itself)
- Experiment (A/B testing)
